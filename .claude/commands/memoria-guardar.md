# /memoria-guardar

Guarda el resumen de la sesión actual en `.claude/memory/session-summaries.md`.

Pasos:
1. Identificar fecha actual (YYYY-MM-DD).
2. Agregar entrada al final de `session-summaries.md` con el formato del skill memoria-persistente.
3. Actualizar `known-issues.md` si hubo cambios.
4. Actualizar `project-decisions.md` si se tomaron decisiones.
5. Actualizar `architecture-log.md` si hubo cambios estructurales.
6. Confirmar al usuario qué archivos fueron actualizados.
