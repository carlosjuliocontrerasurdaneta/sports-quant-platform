# edge-ranking

Analyze all generated picks across MLB, NBA, NFL and NHL.

Create a unified ranking of opportunities.

Requirements:
- Use calibrated probabilities.
- Use ML, RL/Spread and Totals.
- Compute implied probability from odds.
- Compute edge and expected value.
- Rank from highest expected value to lowest.
- Exclude markets failing liquidity or confidence thresholds.
- Output top 100 opportunities.
