# Código cuantitativo y machine learning

Esta referencia aplica únicamente cuando el proyecto contiene modelos estadísticos, machine learning, backtesting, calibración o decisiones cuantitativas.

---

## Código cuantitativo y machine learning

Cuando corresponda, revisar:

- look-ahead bias;
- target leakage;
- contaminación train/test;
- splits temporales;
- features futuras;
- timestamps;
- selección retrospectiva;
- calibración;
- Brier score;
- log-loss;
- ECE;
- tamaño muestral;
- backtesting;
- walk-forward;
- reproducibilidad;
- seeds;
- tuning sobre el conjunto de prueba;
- compatibilidad de artefactos;
- promoción de modelos;
- separación entre código experimental y producción;
- drift;
- estabilidad;
- leakage por agregaciones;
- uso de información posterior al evento;
- métricas mal definidas;
- evaluación in-sample presentada como out-of-sample;
- selección de muestras posterior al resultado.

No presentar resultados sintéticos, in-sample o retrospectivamente seleccionados como evidencia fuera de muestra.
