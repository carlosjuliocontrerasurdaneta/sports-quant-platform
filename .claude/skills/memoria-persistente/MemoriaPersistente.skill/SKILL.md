# MEMORIA PERSISTENTE PRO

## Protocolo de inicio

Leer en este orden:

3. session-summaries.md
4. known-issues.md
5. project-decisions.md
6. roadmap.md
7. memory-index.md

Reportar:

- Última sesión

## Protocolo de cierre

Actualizar:

- session-summaries.md
- project-decisions.md
- known-issues.md
- architecture-log.md
- roadmap.md
- memory-index.md

Nunca inventar memoria.
Solo usar información proporcionada por el usuario o almacenada en los archivos.
