## Detalle de I-1 (decisión de diseño)

`run_league` lee el historial persistido + una ventana de 3 días de `/scores` (The Odds API) y ajusta las ratings **en memoria**, pero nunca guarda esos scores. Sin un backfill periódico, los partidos de más de 3 días que no se backfilleen desaparecen del modelo.

**No se inyectó `upsert` en `daily.py` a propósito:** el store deduplica por clave **cruda** `(date, home, away, game_id)` y el normalizador de nombres solo actúa en memoria; el run diario usa nombres de The Odds API mientras el backfill usa ESPN/MLB, así que persistir desde el daily arriesga **duplicados cross-vendor** que inflarían el Elo.

**Mitigación operativa:** tarea de Windows `SQP_Backfill` semanal (lunes 08:00) que ejecuta `backfill_results.py --days 14` sobre las 19 ligas ESPN/MLB. El solape de 14 días y la deduplicación del store la hacen idempotente; las ligas fuera de temporada devuelven 0 (inofensivo). Salida en `logs/backfill.log`. Probada: exit 0.
